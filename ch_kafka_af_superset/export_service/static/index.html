Подключить дашборд из Superset

Укажите номер дашборда или вставьте ссылку из браузера. Сервис сам создаст карточку отчёта для выгрузки.

  1. Откройте нужный дашборд в Superset.
  2. Скопируйте адрес из строки браузера (или только число из адреса, например 20).
  3. Вставьте сюда и нажмите «Подключить отчёт».

Пример ссылки: http://192.168.14.226:8088/superset/dashboard/20/
